# MamaCare Hub

Build a web dashboard for nurses at Kenyan maternal health facilities called Mama na Mtoto+ CHV Dashboard. Purple brand colour #7C3AED. The dashboard has these pages: 1) Phone OTP login, 2) Dashboard home with stats and quick actions, 3) Register New Mother form that generates an 8-character registration code and sends SMS, 4) Search mothers by phone or name, 5) Mother profile with tabs for Overview, ANC Visits, Lab Results and Vaccinations, 6) Record ANC Visit form with fields for BP, weight, fundal height, fetal heart rate, urine tests and next appointment date, 7) Enter lab results form for blood group, Hb, HIV, urine analysis, blood sugar and syphilis with auto-flagging for abnormal values, 8) Mark vaccination given form, 9) Alerts feed showing all danger sign alerts from this facility. Connect to REST API at https://mama-na-mtoto-api-production.up.railway.app/api. The dashboard must work on mobile browsers since nurses will use it on phones and tablets in the facility
